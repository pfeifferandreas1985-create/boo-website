Privacy

Il tuo Boo. La tua casa. Le tue regole.

Un dispositivo che ascolta ha bisogno di fiducia. Per questo scegli tu dove pensa Boo.: a casa, nel cloud o con l’IA che preferisci.

Boo. Server · a casa

Il cervello di Boo. abita da te.

  • Riconoscimento vocale, modello linguistico e voce girano sul tuo PC con scheda grafica.
  • Nessuna registrazione vocale esce di casa.
  • Nessun abbonamento per il server di casa.
  • Console propria: memoria, conoscenze, voci, routine, calendario.
  • Area privacy con tempi di cancellazione, cancellazione per persona o dispositivo ed estratto dei dati in ZIP.
Cloud

Senza server proprio.

  • Un servizio di IA esterno riconosce la voce e genera la risposta.
  • Il display mostra il simbolo di una nuvola finché Boo. parla tramite il cloud.
  • Se il tuo server di casa è raggiungibile, all’accensione Boo. passa automaticamente a lui.
  • Per la serie stiamo valutando quale fornitore cloud soddisfi meglio i requisiti di protezione dei dati.
La tua IA · via API

Claude & co. come cervello.

  • Boo. si può collegare anche a Claude e ad altri servizi di IA.
  • Scegli tu il modello linguistico – volto, ruoli e carattere restano di Boo.
  • Valgono le condizioni del servizio che colleghi.
Data center Boo.Previsto

Server propri per Boo.

  • Se Boo. cresce, costruiremo un nostro data center di IA.
  • Boo. penserà allora sui nostri server invece che presso un fornitore esterno.
  • Per questo ci sarà un abbonamento mensile. Il Boo. Server di casa resta senza abbonamento.
Principi

Cosa promette Boo.

Ascolto

Solo quando lo sollevi

Boo. non ha una parola di attivazione e non ascolta di continuo. Ti ascolta quando lo sollevi o attivi il vivavoce – lo vedi dall’anello luminoso.

Registrazione

Sempre annunciata. Mai di nascosto.

Boo. registra le riunioni solo se lo vuoi tu. Annuncia la registrazione e mostra un anello rosso con «REC».

Memoria

Vedi cosa sa di te

Ciò che Boo. ricorda di te è nell’app. Cancella singole voci o azzera tutto – quando vuoi.

Onestà

Ti dice che è un’IA

Boo. è un’intelligenza artificiale e non si spaccia per un essere umano. I ruoli sono indicati come simulazioni di IA.

Voci

Nessuna voce altrui

Boo. parla con voci sintetiche. Riprodurre voci reali è possibile solo con il consenso della persona.

Bambini

Protezione minori con PIN

I contenuti non pensati per i bambini restano invisibili senza PIN.

A oggi

Boo. è un prototipo.

I dispositivi della fase di test funzionano a scelta con il Boo. Server o tramite un servizio cloud. Come vengono trattati i dati nell’uso in cloud lo definiremo in modo vincolante prima della vendita e lo descriveremo nell’informativa sulla privacy del dispositivo.
